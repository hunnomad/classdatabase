# CHANGELOG

## v1.3.0 - 2026-10-28
- PHP 8.5 compatibility: `mongodb/mongodb` now accepts `^1.19 || ^2.0` (ext-mongodb 2.x builds for PHP 8.5)
- `ext-redis` moved from `require` to `suggest` (no longer required for non-Redis users)
- **Changed:** connection errors now throw `RuntimeException` (original in `getPrevious()`) instead of `echo` + `die()`
- Errors are logged via `error_log()` only, no more `error_log.txt` written into `vendor/`
- Fixed: placeholders are generated by index, so column names like `u.id` work in insert/select/update/delete
- Fixed: `select()` limit/offset uses `OFFSET … FETCH` on SQL Server and Oracle (instead of invalid `LIMIT`)
- Fixed: MongoDB connection without username (invalid `mongodb://:@host` URI); credentials with special characters
- Fixed: Redis connect/auth failures are no longer silently ignored; Redis 6 ACL user supported
- Fixed: `rawQuery()` 1-based positional params (`[1 => 'a']`) were shifted by one; empty param key warning
- `rawQuery()` detects result sets via `columnCount()` (supports `RETURNING`, `EXEC`, comments before `SELECT`)
- `insert()` / `update()` throw a clear exception on empty `$data`

## v1.1 - 2025-02-XX
- Added CRUD operations
- Added rawQuery()
- Added transaction helpers
- Added Redis/Mongo/PDO multi-driver handling
- Initial public release
